# OPENGL.DLL

OpenGL: the gl* dispatch over the host renderer and the PGL (pgl*) entry points.

- IBM source: `src/gos/3d/` (`OPENGL/GLU/libutil`, `OPENGL/GLU/libtess`, `SOFTGL/GLPIPE`).
- Evidence: Strings in the unpacked OPENGL.DLL; LX entry table of OPENGL.DLL
  (inventory `modules.json`, 2082c1576496…, "OpenGL 1.0 version 9632"): 369
  code exports, 19 of them `pgl*`; it imports RASTER, the software renderer.
- In Warp 4.52: Real code; `pgl*` are OPENGL.DLL exports, not a separate DLL.
- In 2ine: OPENGL exports the gl*, glu* and pgl* entries itself. Its Warp
  ordinal set equals Warp's entry table for all 369 names; the GOLD 1.1 set
  serves applications built against IBM's later OpenGL.
- Exports: generated by `tools/codegen/gen_opengl.py` from `tools/codegen/data/opengl.json`
  (Warp and GOLD ordinal sets) into `generated/`.

## Units

IBM's unit names for OPENGL are known only for GLU and the software pipeline,
which 2ine does not implement; the 2ine units are named by function.

| 2ine unit | APIs and services |
|---|---|
| `module.c` | Entry, export tables, the gl* wire callbacks for both CPU workers |
| `pgl.c` | pgl* (contexts, visual configurations, current bindings, buffers, fonts) |
| `copy.c` | pglCopyContext attribute copying |
| `custom.c` | gl* entries with hand-written marshalling: driver strings, render-mode buffers |
| `arrays.c` | Client vertex arrays and draw-time snapshots |
| `memory.c` | Guest pointer extents for pixel and evaluator data |
| `internal.h` | Shared PGL handle and context types |
