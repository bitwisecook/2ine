# OPENGL.DLL

OpenGL: the gl* dispatch over the host renderer and the PGL (pgl*) entry points.

- IBM source: `src/gos/3d/` (`OPENGL/GLU/libutil`, `OPENGL/GLU/libtess`, `SOFTGL/GLPIPE`).
- Evidence: Strings in the unpacked OPENGL.DLL.
- In Warp 4.52: Real code; `pgl*` are OPENGL.DLL exports, not a separate DLL.
- Exports: generated by `tools/gen_opengl.py` from `tools/data/opengl.json` (Warp and GOLD ordinal sets).
