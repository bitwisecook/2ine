# 2ine

*What is this?*

It's a program that loads and runs OS/2 .exe files on Linux and macOS.

*Does it work?*

It runs command line OS/2 apps, including Microsoft, IBM and Watcom developer tools.

*Why?*

Because.

*Does it work on Mac OS X?*

Yes. ARM64 macOS uses Unicorn for mixed 16/32-bit x86 execution. Linux x86
can run it natively. No Linux VM or Rosetta needed. Windows is not supported.
