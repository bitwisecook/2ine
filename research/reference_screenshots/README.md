# Application reference screenshots

Stock OS/2 Warp 4.52 screenshots are retained here by application. Each application
has a provenance manifest identifying media/build hashes, display configuration,
input steps and screenshot hashes. These are visual references for 2ine's control
and layout review. Allow differences in font shapes, antialiasing and small text
metrics; missing controls, wrong state and clipped content remain defects.

Application binaries, VM disks and original font files are supplied separately
and are not stored here. Capturing stock OS/2 does not verify reconstructed OS/2
artifacts or qualify an entire application.

Current priority: Word Pro, then 1-2-3. Other SmartSuite applications are deferred.
